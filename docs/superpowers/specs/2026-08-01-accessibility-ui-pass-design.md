# Accessibility & UI pass (PWA + mobile)

Approved local-first pass. No production push until requested.

## Goals

- WCAG AA contrast for body/muted text (light + dark)
- Body text floor ~14px; no 9–11px labels for meaning
- Softer decorative patterns behind content
- Larger, clearer icons
- Home: AQI status > number; larger location chip
- Search placeholder “Search city”
- Notifications: one type icon; clearer mark-as-read
- 7-day chart: per-day AQI colors + brand green for Good
- Map: loading message (10–15s first load)

## Keep

Clean layout, onboarding, white+dark text, VoiceOver/TalkBack, hierarchy praised in review.
