# contributing

thanks for your interest. here's how to help.

## reporting issues
- open a github issue with a clear title
- include steps to reproduce the bug
- mention your browser/device if it's a frontend issue

## code contributions
1. fork the repo
2. create a feature branch (`git checkout -b feature/your-idea`)
3. make your changes
4. test locally (backend: `uvicorn main:app --reload`, frontend: `npm run dev`)
5. commit with a clear message
6. open a pull request

## what we need help with
- translations for more african languages
- model accuracy improvements
- mobile ux testing

## code style
- python: follow pep8
- javascript: use prettier defaults
- keep it simple, no over-engineering

questions? open an issue.
